# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：骨髓增殖性肿瘤（PV/ET/PMF 等）患者与照护者，尤其是需要长期随访、记录血常规与症状、准备就诊提问的人

场景：确诊后理解疾病与随访节奏，持续记录血常规、症状、治疗与就诊问题，复诊前整理一页摘要，并了解可核对的临床研究线索

核心流程：
1. 选择或新建我的档案，查看当前病程状态与最近指标
2. 记录一次血常规、症状、治疗或就诊问题
3. 在趋势与一图秀中回看变化，准备复诊摘要
4. 在临床研究页按已确认字段检索与保存候选线索

完成结果：患者能在同一份本地档案中连续记录并回看自己的指标与症状，复诊前导出/打印一页摘要，且清楚哪些信息只是候选、需与医生核对

初始布局选择：business-first
