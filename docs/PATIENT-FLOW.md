# 患者流程（触发 → 动作 → 产物）

## 主流程 1：刚确诊，建立自己的账本

- 触发：拿到诊断，记不住医生说的名词，下一次复诊不知道问什么。
- 动作：新建“我的档案”（只填名称/亚型/确诊年月，均可跳过）→ 记第一条血常规或症状 → 在首页看“下一次复诊带什么”。
- 产物：一个 `is_demo=0` 的本地档案；一条可追溯的记录；一页复诊问题清单。
- 失败路径：目录不可写/接口失败 → 页面内可读原因 + 重试；不静默丢记录。

## 主流程 2：长期随访，复诊前整理

- 触发：每 1–3 个月复诊，化验单与症状散在相册/纸上。
- 动作：补录最近 3 次血常规 → 标一次“这周特别累” → 在指标页看 Hb/PLT/WBC 各自趋势 → 勾三件最想问的事。
- 产物：一页摘要（最近值、变化、症状、问题），可打印/导出。
- 边界：不生成“病情好转/恶化”的结论；只写“记录里是……”。

## 主流程 3：看到一项研究，判断要不要问

- 触发：群里转发一条试验招募。
- 动作：研究页 → 匹配（看分母与证据缺口）→ 检索（按药名/登记号）→ 收藏并标“准备问”。
- 产物：一条带来源、快照日期、三态证据链的候选线索；一句“不是入组资格”。
- 失败路径：通道 FAILED/NEEDS_SETUP 逐条显示，不能写成“没有研究”。

## 主流程 4：隐私与换目录

- 触发：借出电脑，或想把资料放进加密盘。
- 动作：单条记录设为私密 → 列表/导出立即隐藏；设置里换资料目录 → 选择器校验 → 回显 → 重开仍在。
- 产物：私密标记落库；目录选择落 `app_setting`；旧目录数据不自动搬迁，明确提示。

## 情绪与可读性

- 刚确诊的人需要“少而确定”：首页只显示三条今天能做的事。
- 长期随访的人需要“可回看”：筛选、比较、导出，不强迫看所有历史。
- 任何时候都不出现“你属于高危/你适合入组”这类判断。
