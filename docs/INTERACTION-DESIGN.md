# 交互设计（IP1）

## 信息架构

```text
语义 header（品牌 / 版本 / 一句话状态 / 资料目录 / AI 对话）
└─ 业务 iframe
   ├─ 左 rail：档案切换 + 一级导航（概览 / 记录 / 指标 / 研究 / 资料 / 设置）
   └─ 主区：页面标题 + 状态条 + 内容
      ├─ 概览：病程卡 / 今日三件事 / 最近指标 / 症状负担 / 复诊准备
      ├─ 记录：8 类入口 + 最近记录 + 空态 CTA
      ├─ 指标：分类卡（3D 翻面）/ 单指标详情 / 一图秀（独立 tab）
      ├─ 研究：匹配 / 检索 / 收藏三子页 + 右侧详情浮窗
      ├─ 资料：来源、导出、目录
      └─ 设置：目录 / 临床数据库 / 隐私 / 关于
```

## 视觉基因

- 主基因：瑞士平面/包豪斯（12 列栅格、hairline、左对齐、无阴影）。
- 辅基因：东方留白（大段呼吸、标题前 1 个细胞团标记，不铺装饰）。
- 情绪：**被托住、可核对、不吓人**。不是“医疗蓝”，不是“AI 紫”。
- 色板 ≤4：纸白 `#F6F3EC`、墨 `#1E2A24`、深绿 `#2F5D4E`、陶土 `#B4552D`；浅灰仅作分隔。
- 圆角统一 2px；标题无渐变；图表单色阶 + 陶土强调。
- 字体：`Inter / "Noto Sans SC" / "PingFang SC"`；数字等宽。
- 动效：卡片 180ms 翻面；减少动效时直接切内容；无循环动画（品牌细胞团静止）。

## 关键交互

### 档案

- 左 rail 顶部显示当前档案名 + “合成示例/我的档案”标签；点击打开档案管理（整页侧滑，不是小弹窗）。
- “＋ 新建我的档案”是档案级入口；表单只要求名称，亚型/确诊年月可空；创建后立即切换并清空筛选。
- 切换档案：所有页面重渲染；未发送草稿按档案暂存，不串档。

### 记录

- 8 类用同一套抽屉/整页表单，字段按 kind 变化；必填只有“日期 + 一项内容”。
- 保存中禁用按钮；成功后 toast“已保存到本机数据库”；失败保留表单并显示原因。
- demo 档案也可新增记录，但标“写入演示档案，仅本机”。

### 指标

- 分类顺序固定：血细胞 / 炎症与代谢 / 脾脏与体型 / 其他。
- 卡片正面：最近值 + 单位 + 可比差值 + 次数 + 日期 + 来源；背面：固定高度趋势，不展开。
- 单点不连线；空窗口给“还没有足够数据”，不画 0。
- 单位/方法变化拆可比组，卡头提示“不可直接比较”。

### 研究

- 匹配页先显示档案字段网格（已确认/待确认），只有已确认字段参与。
- 候选池卡头：已载 N / 返回 M / 不是全库扫描 / 快照日期 / 通道终态。
- 匹配卡：pct 方块 + `n / m 项对得上 · k 项待确认` + 证据链（✕/? 在前）+ “不是入组资格”。
- 检索页无 `%`、无分数；收藏零副作用。

### 疾病概要

- 顶栏 `?` 与首页状态卡各一个入口，打开同一个 `#disease-primer` 整页。
- 四段顺序固定；每段来源行；底部“返回”与“关闭”两个独立按钮。
- Esc/浏览器返回只退一层；关闭后焦点回触发按钮，滚动位置不变。

### 目录与 AI

- 资料目录：真选择器 → 四类拒绝 → POST → 回显；重开读 `app_setting`。
- AI 对话：顶栏五态按钮；无会话不 disabled；创建失败/取消都有可读提示；草稿只填不发。

## 响应式

- ≥1100：左 rail 220 + 内容两栏。
- 768–1099：rail 收为横向 chips；指标卡两列。
- <768：rail 顶部横向滚动；卡片单列；表格变卡片；图表容器内横向滚动。
- 390：无页面横向溢出；触控目标 ≥44；字号不小于 12.5。
