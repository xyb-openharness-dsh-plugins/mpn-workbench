# 小髓宝 MPN 患者工作台 · SPEC（v0.2 原型合同）

> 品牌名为家族占位名，**待用户追认**。本文件是患者工作台范围与验收口径，不是诊疗指南。
> 证据边界：0 位患者访谈、0 位临床医生审核；所有阈值、提醒与文案均标“待临床核对”。
> 合成数据只用于演示结构与交互，不是真实病例，不可用于推断任何人的病情。

## 1. 服务对象与任务

服务对象：骨髓增殖性肿瘤（MPN）患者与照护者，涵盖 PV、ET、PMF 等亚型；优先照顾**刚确诊、记录少**与**长期随访、记录多**两类人。

一次核心任务（端到端）：

1. 打开自己的档案，看到“今天离确诊多久、最近一次血常规、最近一次不舒服、下一次复诊要问什么”。
2. 补记一次血常规/症状/治疗/就诊问题；保存后刷新仍在。
3. 在指标趋势页按类别看单指标变化，不把不同指标画成同一条“病情分”。
4. 复诊前把“最近变化 + 我在意的三件事 + 要问医生的问题”整理成一页摘要。
5. 在临床研究页按已确认档案字段看候选线索，知道分母、证据缺口与“不是入组资格”。

## 2. 范围

### 2.1 必须有

- 多档案：两套合成示例（A 刚确诊、B 长期随访）+ 用户自建档案（is_demo=0），可列、可切、会话/草稿按档案隔离。
- 首页：病程状态卡、最近指标、症状负担、复诊准备、疾病概要「?」双入口。
- 记录：8 类记录（症状/血常规/治疗/问题/就诊/报告/文档/心情），全部走 API 落 sqlite；失败可读、可重试。
- 指标：按类别分组；单指标趋势，按该指标全期 min/max 归一化；单点不连线；空窗口空态；3D 卡片固定高度翻面。
- 一图秀：多指标时间轴 + 独立治疗/事件泳道；治疗条与数据区分层；移动端轨道 minmax(0,1fr)。
- 临床研究：建档字段 → 检索 → 匹配（pct=符合÷已对照、待确认按 0、<2 项不给百分数、四档）→ 收藏三态；候选池卡头写已载/返回/快照日期。
- 资料与设置：资料目录真入口、临床数据库通道终态、隐私开关、导出、关于。
- 疾病概要：整页四段（definition / evidence / landscape / trend），来源行、返回/关闭两入口、Esc/浏览器返回只退一层。

### 2.2 本轮不做

- 不做诊断、分期判断、预后预测、用药推荐、入组资格判断。
- 不接真实医院系统、不抓取真实病历、不自动上传任何资料。
- MinerU 报告解析只保留入口说明与“未接入”状态，不伪造解析结果。
- 不做社区、排行榜、医生端工作流。

## 3. 数据与事实纪律

- 演示档案固定 `is_demo=1`，有可见“合成示例”标记，不可删、不被用户记录覆盖。
- 用户档案 `is_demo=0`，从空记录开始也能用；没有记录时显示空态 CTA，不借用 demo 数据填充。
- 指标值保留原始单位、参考范围、机构、方法；单位/方法变化拆可比组，不合并成一条曲线。
- 分级是“对照 CTCAE v5.0”的派生展示，不落库、不写成诊断；没有绝对数值界限的项不启用。
- 临床研究登记 ≠ 有效 ≠ 安全 ≠ 可入组；状态一律“登记状态，未核实”。
- 趋势段只写已发生事实（指南版本、监管批件、登记数量与阶段分布），不写展望/推荐。

## 5. 非功能

- 375 / 390 / 768 / 1280 宽可用；业务区可窄至 320。
- 键盘可完成打开/关闭概要与档案管理；焦点回收、滚动位置恢复。
- 正文 12.5–15px；对比度 AA；减少动效时无旋转/翻面动画，直接呈现终态。
- 任何错误都在界面内说明“发生了什么、可以再做什么”，不裸 throw、不白屏。
