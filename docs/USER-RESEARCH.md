# 用户研究（证据分层）

## 结论先行

- **0 位患者访谈、0 位照护者访谈、0 位临床医生审核**。本文件不冒充一手引语。
- 下列需求来自公开指南/患者组织材料与家族仓的通用结构，属于**二手证据 + 设计推断**；需要真实访谈验证。
- 不写“患者说……”；需要引语的位置统一标“待访谈”。

## 待访谈问题（不是引语）

1. 刚确诊时，你最想先知道哪三件事？哪些词听不懂？
2. 复诊前你会怎么整理化验单和问题？现在最费时的一步是什么？
3. 血常规里你会看哪几个数？医生说的“稳定”你怎么理解？
4. 疲劳/瘙痒/骨痛/腹胀，哪个最影响你？你愿意怎么记？
5. 看到临床试验招募，你最怕误解什么？
6. 你愿意把资料放在哪个目录？会不会与家人共用电脑？
7. 哪些内容你希望永远不出现在导出里？
8. 你希望首页显示“今天离确诊多久”吗？会不会增加压力？

## 已知风险

- 把“随访工具”做成“诊断工具”：所有页面禁止判读词。
- 把试验匹配做成“入组概率”：分母与“不是入组资格”必须同屏。
- 把症状量表当诊断：标“自评，不用于判断病因”。
- 只用一套 demo：新患者路径空白；必须两套 + 空档案可用。
