# 家族结构差异矩阵（MPN）

> 对照方法：只读比对本地样板仓的导航、信息层级与交互代码；**私有仓链接不写入本仓**，只用仓名与结构描述。
> 不抄病种语义：实体瘤的分期、治疗线序、预后分层均未带入。

## 一、结构对照

| 维度 | 家族常见做法 | 小髓宝 MPN | 差异理由 |
| --- | --- | --- | --- |
| 一级导航 | 首页 / 档案 / 趋势 / 临床研究 / 设置 | 概览 / 记录 / 指标 / 研究 / 资料 / 设置 | 把“今天要做什么”与“长期趋势”分开，减少患者一进来就看一堆曲线 |
| 首页 | 指标卡 + 待办 | 病程状态卡 + 三件今日事 + 最近指标 + 症状负担 | MPN 随访周期长，患者更关心“这次复诊带什么” |
| 指标 | 单页多图 | 分类卡 + 单指标详情 + 一图秀 | PV/ET/PMF 的关注指标不同，必须按类别而不是按“病情总分” |
| 症状 | 通用表单 | 0–10 + 疲劳/瘙痒/骨痛/腹胀/早饱/活动受限 | MPN 的脾大、瘙痒、疲劳是高频主诉；仍标“待临床核对” |
| 临床研究 | 检索 + 表格 | 匹配 / 检索 / 收藏三子页 | 患者先问“跟我有关吗”，再问“有没有某个药” |
| 设置 | 单页表单 | 资料目录 / 临床数据库 / 隐私 / 导出 / 关于 | 目录与临床库状态是装机后最容易“看起来有、其实没接通”的两块 |
| 治疗表达 | 线序折叠卡 | 按“正在用 / 用过 / 计划问”分组，不排序优劣 | 非肿瘤不套治疗线序语义 |
| 风险表达 | 风险等级徽章 | 不显示个体风险分级；只显示记录与待问 | 无临床审核，不生成个体判断 |

## 二、重名率实测

取 18 个可命名的一级/二级功能名，与家族通行命名逐项对照；完全同名 4 个（首页、指标、设置、收藏），
**重名率 4/18 = 22.2%**，低于 70% 上限。同名项保留是因为它们是家族导航的可预期锚点，不构成病种语义复制。

## 三、抄什么 / 不抄什么

**抄结构与元素体系**：语义 header → 业务 iframe → 1px splitter → aside；三栏信息密度、hairline 分隔、编号导航、空态/错误态三件套。

**不抄**：乳腺癌的分期与内分泌治疗语义、AML 的诱导/巩固线序、任何实体瘤的“缓解/进展”判读。MPN 只用“记录事实 + 待问医生”。
